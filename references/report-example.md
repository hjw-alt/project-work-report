## 核对写法

- 三条资料都记录同一项试讲时，在简报里记一次。
- 周报跨月时按实际工作日期归月。累计数字有截止日期时保留相应口径。
- Git 提交确认功能改动，试用记录确认验收状态。只有本地验证记录时，成果写「本地验证完成」，有后续计划可补「待联调」。
